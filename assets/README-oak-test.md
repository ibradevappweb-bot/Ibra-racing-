# Realistic oak forest asset

The forest test branch loads `./assets/oak-detailed-optimized.glb`.

Add the optimized GLB supplied with this change at exactly:

`assets/oak-detailed-optimized.glb`

The model is an optimized copy of the user-provided CC0 oak: 4 merged material meshes, approximately 58,392 triangles, 1.64 MB. Until the asset is uploaded, the game keeps its existing procedural trees as a safe fallback.

Only 40 near-road tree positions are replaced in this first mobile performance test. The remaining background trees, city, BMW, physics, controls and camera are unchanged.
